### 오늘의 회고
- accuracy, precision, recall, f1-score의 개념과 암 진단 모델에서 recall이 중요한 이유를 설명하시오.
    - accuracy: 모델이 판단한 모든 샘플 중에서 모델의 판단이 실제와 일치하는 샘플의 비율
    - precision: 모델이 양성으로 판단한 것 중에서 실제 양성인 샘플의 비율
    - recall: 실제 양성인 샘플 중에서 모델이 양성으로 판단한 샘플의 비율
    - f1-score: precision과 recall의 조화평균. 
    - recall이 중요한 이유는 모델이 실제 사례 중에서 암을 얼마나 잘 잡아낼 수 있는지 판단하는 지표이기 때문이다.
- 데이터 불균형이 심할 때 왜 accuracy가 부적합한지 설명하시오.
    - 데이터 불균형이 심하면 샘플도 그만큼 불균형이 심하기 때문에 accuracy가 높아도 수가 적은 샘플과 비슷한 유형의 데이터는 잘 못 잡아내기 때문.
- feature selection에서 filter, wrapper, embedded 방법의 차이를 설명하고 각각의 장단점을 비교하시오.
    - filter: 특성의 통계적 속성에 기반하여 특성의 관련성을 평가하는 방법
    - wrapper: 모델 성능을 기준으로 덜 중요한 특성을 반복적으로 제거하는 방법
    - embedded: wrapper와 filter 방법을 조합.
- tree 기반 모델이나 gradient boosting 모델 사용할 때 feature selection이 필요한가?
    - 모델 복잡도나 과적합 방지
    - 연산 효율성 및 유지보수
    - feature selection이 없으면 다중공선성으로 인해 변수 중요도를 측정하기 어려워짐.
- 강화학습에서 탐색과 활용은 어떤 개념이고 왜 중요한가?
    - 탐색: 에이전트가 이전에 해보지 않았던 선택을 하는 과정. 환경에 대해 더 많은 정보를 수집하고 현재 알고 있는 정보보다 더 큰 보상을 얻을 수 있기 때문.
    - 활용: 에이전트가 지금까지 경험을 통해 쌓은 지식을 바탕으로 가장 큰 보상을 줄 것으로 예상되는 행동을 선택하는 과정. 현재 알고 있는 최선의 선택을 통해 즉각적인 보상을 극대화하기 위해.
