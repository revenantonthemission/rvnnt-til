### 오늘의 회고
- 퍼셉트론을 설명하시오. 그리고 이 모델의 한계와 이를 해결하기 위한 방법을 설명하시오.
    - 퍼셉트론은 인공 신경망의 가장 기본적인 형태로, 노드와 가중치로 구성된 모델입니다. 입력값에 가중치를 곱한 후, 활성화 함수를 통해 출력값을 결정합니다. 하지만 퍼셉트론은 선형적으로 구분 가능한 문제만 해결할 수 있는 한계가 있습니다. 이를 해결하기 위해 다층 퍼셉트론(MLP)과 같은 심층 신경망이 개발되었습니다.
- 비지도 클러스터링 모델 K-means와 DBSCAN의 개념과 차이점을 설명하시오.
    - K-means는 데이터를 K개의 클러스터로 나누는 알고리즘으로, 각 클러스터의 중심을 계산하여 데이터를 할당합니다. 반면 DBSCAN은 밀도 기반 클러스터링 알고리즘으로, 데이터 포인트 간의 거리를 기준으로 클러스터를 형성합니다. K-means는 구형 클러스터에 적합하지만, DBSCAN은 다양한 형태의 클러스터를 탐지할 수 있습니다.
- 딥러닝 비지도 학습 모델 AutoEncoder의 구조와 작동 원리를 설명하시오.
    - AutoEncoder는 입력 데이터를 압축하여 잠재 공간(latent space)에 표현하는 비지도 학습 모델입니다. 인코더와 디코더로 구성되어 있으며, 인코더는 입력 데이터를 낮은 차원으로 압축하고, 디코더는 이를 다시 원래 차원으로 복원합니다. AutoEncoder는 데이터의 중요한 특징을 학습하는 데 사용되며, 노이즈 제거, 차원 축소 등에 활용됩니다.
- 일반 AutoEncoder와 Variational AutoEncoder의 차이점을 설명하시오.
    - 일반 AutoEncoder는 입력 데이터를 단순히 압축하고 복원하는 반면, Variational AutoEncoder(VAE)는 잠재 공간에서 확률 분포를 모델링합니다. VAE는 입력 데이터를 잠재 공간의 평균과 분산으로 표현하며, 이를 통해 새로운 데이터를 생성할 수 있습니다. VAE는 생성 모델로서 이미지 생성, 데이터 증강 등에 활용됩니다.
- 앙상블 기법인 Bagging과 Boosting의 차이점을 설명하시오.
    - Bagging은 Bootstrap Aggregating의 약자로, 여러 개의 모델을 독립적으로 학습시키고 예측 결과를 평균화하여 최종 예측을 도출하는 방법입니다. 반면 Boosting은 모델을 순차적으로 학습시키며, 이전 모델이 잘못 예측한 데이터에 더 큰 가중치를 부여하여 다음 모델이 이를 개선하도록 하는 방법입니다. Bagging은 모델의 분산을 줄이는 데 효과적이고, Boosting은 모델의 편향을 줄이는 데 효과적입니다.
- Gradient Boosting의 대표적인 모델과 각각의 특징을 설명하시오.
    - Gradient Boosting의 대표적인 모델로는 XGBoost, LightGBM, CatBoost 등이 있습니다. XGBoost는 효율성과 성능이 뛰어나며, 병렬 처리를 지원합니다. LightGBM은 대용량 데이터에 적합하며, 트리 기반 학습을 최적화하여 빠른 학습 속도를 제공합니다. CatBoost는 범주형 변수를 효과적으로 처리할 수 있는 기능을 갖추고 있으며, 과적합 방지에 강점을 가지고 있습니다.
