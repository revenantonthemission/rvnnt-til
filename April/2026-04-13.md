### 오늘의 회고
- 과적합에 대해서 설명하고 해결하기 위한 방법을 설명하시오.
    - 과적합은 모델이 학습 데이터에 지나치게 가까운 결과를 도출하도록 학습되어 실제 데이터를 대상으로는 오히려 적합도가 떨어지는 현상을 뜻한다. 이를 해결하기 위해서는 더 많은 데이터를 확보하거나 교차 검증, 정규화, 드롭 아웃, 조기 종료, 앙상블 기법 등의 방법을 적용해야 한다.
- Random Forest가 일반적으로 Decision Tree 대비 성능이 좋은 이유.
    - Random Forest는 트리 학습 과정에서 각 노드에 분할할 특성을 무작위로 선정한다. 일반적인 의사결정 트리는 모든 특성 중에서 최적의 분할 기준을 찾지만, Random Forest에서는 각 노드에서 일부 특성만 무작위로 선택하여 최적의 분할을 수행한다. 덕분에 트리 간의 상관관계가 낮아져 모덜의 성능이 더욱 향상된다.
- K-fold Validation에 대해서 설명하고 사용하는 이유를 설명하시오.
    - K-fold Validation은 전체 데이터를 K개의 폴드로 나누고 1개의 폴드를 검증 데이터로, 나머지 폴드를 학습 데이터로 사용하는 과정을 K번 반복해 각 폴드에서의 검증 결과의 평균을 최종 검증 결과로 사용하는 모델 검증 방법이다. 이 방법을 사용하면 특정 데이터에 대한 과도한 편향을 줄이고 모델의 일반화 성능을 높일 수 있다.
- K-NN 알고리즘에 대해서 설명하고 memory-based 알고리즘으로 불리는 이유는?
    - K-NN 알고리즘은 새로운 데이터에 대한 결과를 주변에 있는 가장 가까운 K개의 데이터를 조합하여 구성하는 알고리즘이다. 이 알고리즘이 메모리 기반 알고리즘이라 불리는 이유는 데이터를 학습할 때가 아니라 학습한 데이터로 추론할 때 이웃 데이터를 찾기 때문이다.
- Linear Regression과 Logistic Regression의 차이
    - 선형 회귀는 종속 변수(y)와 독립 변수(x) 간의 선형 관계를 모델링하는 회귀 분석 기법이다.
    - 로지스틱 회귀는 입력값을 이용해 사건이 일어날 확률을 계산하고, 그 확률을 기준으로 분류하는 알고리즘이다.
- 대표적인 Ensemble 기법의 종류와 차이점을 설명하시오.
    - 배깅: 여러 개의 모델을 독립적으로 학습한 후, 개별 모델의 예측값을 결합하여 최종 결과를 도출
    - 부스팅: 개별 모델을 순차적으로 학습하며, 이전 모델이 틀린 부분을 보완하는 방식
    - 스태킹: 서로 다른 알고리즘을 결합하여 최종 모델(메타 모델)을 학습시키는 방식
